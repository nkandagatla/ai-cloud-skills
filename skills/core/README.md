# Core (guardrails and cross-cloud)

Generated by `npm run build`. Do not edit by hand.

## User-invoked

Run them as commands (for example `/ask-skills`). The model does not trigger them on its own.

- **[ask-skills](./ask-skills/SKILL.md)**: Router for the company skills library. Use when you are not sure which skill or flow fits a task - cloud (AWS, Azure, GCP), infrastructure, git, languages (HTML/CSS, JS/TS, Node.js, Python, Java, Go, .NET, shell), databases, security, or AI token cost.
- **[cloud-mcp-setup](./cloud-mcp-setup/SKILL.md)**: Connect AI agents to AWS, Azure and Google Cloud through official MCP servers in read-only mode, with dedicated least-privilege identities, for Claude Code, Cursor, VS Code Copilot, Gemini CLI and Codex. Use when the user wants the agent to query live cloud resources, docs or pricing through MCP.
- **[setup-cloud-skills](./setup-cloud-skills/SKILL.md)**: One-time setup per repository. Use when installing these skills in a repo or when environments change. Interviews the user and writes CLOUD.md (environments, accounts, regions, IaC, tagging, change process) and .cloud-guard/policy.json so the cloud skills and the cloud-guard hook know what is production.
- **[well-architected-review](./well-architected-review/SKILL.md)**: Architecture review of a workload against the AWS Well-Architected Framework, Azure Well-Architected Framework and Google Cloud Architecture Framework pillars (security, reliability, cost, performance, operational excellence, sustainability), producing a prioritized risk register. Use when reviewing a design, a new service before launch, or an existing workload's health.
- **[write-company-skill](./write-company-skill/SKILL.md)**: Author a new company skill (or improve an existing one) for this library - scoping, the SKILL.md template, guardrail requirements, examples that pass the guard, review checklist, and the build/validate steps. Use when a team wants to document a process, platform or standard as an agent skill.
