# Google Cloud Storage

Load `cloud-guardrails`. Do not read or download object contents unless the user asks for a specific object; inspect metadata instead.

## 1. Bucket baseline

```hcl
resource "google_storage_bucket" "orders" {
  name                        = "acme-orders-prod-usc1"
  project                     = var.project_id
  location                    = "US-CENTRAL1"            # or dual-region (e.g. NAM4) / multi-region per DR needs
  storage_class               = "STANDARD"
  uniform_bucket_level_access = true
  public_access_prevention    = "enforced"
  versioning { enabled = true }
  soft_delete_policy { retention_duration_seconds = 1209600 }   # 14 days
  encryption { default_kms_key_name = var.cmek_key_id }          # if CMEK required (grant GCS service agent encrypter/decrypter)
  lifecycle_rule {
    condition { num_newer_versions = 5, with_state = "ARCHIVED" }
    action    { type = "Delete" }
  }
  lifecycle_rule {
    condition { age = 1, with_state = "ANY", matches_prefix = [] }
    action    { type = "AbortIncompleteMultipartUpload" }
  }
  logging { log_bucket = var.access_log_bucket }   # or Data Access audit logs for storage.googleapis.com
  labels = local.labels
  lifecycle { prevent_destroy = true }
}
```

Org policies `storage.publicAccessPrevention` and `storage.uniformBucketLevelAccess` enforce the two key settings everywhere. Retention policy + **Bucket Lock** (WORM) for compliance archives: locking is irreversible (human decision).

## 2. Access patterns

| Need | Pattern |
| --- | --- |
| Workload | SA with `roles/storage.objectViewer` / `objectUser` / `objectCreator` **on the bucket**, IAM Conditions for prefixes (`resource.name.startsWith("projects/_/buckets/B/objects/incoming/")`) |
| Humans | Groups with bucket-level roles; Data Access logs for sensitive buckets |
| Temporary external access | **V4 signed URLs** generated by the app's SA (via `signBlob` with impersonation, no keys), short expiry; or signed policy documents for uploads |
| Public website/content | External HTTPS LB + Cloud CDN with **backend bucket** private access (signed requests) instead of `allUsers`; any truly public bucket needs an approved org-policy exception |
| Perimeter | VPC Service Controls around sensitive buckets |

## 3. Read-only discovery

```bash
gcloud storage buckets list --project=P --format="table(name,location,storage_class,uniform_bucket_level_access,public_access_prevention,default_kms_key)"
gcloud storage buckets describe gs://B --format="yaml(iamConfiguration,versioning,soft_delete_policy,retention_policy,lifecycle_config,encryption,logging)"
gcloud storage buckets get-iam-policy gs://B --format=json | jq '.bindings[] | {role, members}'
gcloud storage ls --long gs://B/prefix/ | head -20          # names/sizes only
gcloud storage du -s gs://B --readable-sizes
gcloud asset search-all-iam-policies --scope=organizations/ORG --asset-types="storage.googleapis.com/Bucket" --query="policy:(allUsers OR allAuthenticatedUsers)"
```

## 4. Troubleshooting 403

1. Principal (ADC user vs SA vs impersonated SA); `gcloud config list`.
2. Bucket IAM includes the role with the needed permission (`storage.objects.get` / `list` / `create`); IAM Condition matches the object path.
3. Uniform bucket-level access means object ACLs are ignored: grant via IAM.
4. CMEK: GCS service agent (`service-PROJECT_NUMBER@gs-project-accounts.iam.gserviceaccount.com`) needs `roles/cloudkms.cryptoKeyEncrypterDecrypter`; key enabled.
5. VPC-SC: request from outside the perimeter (`VPC_SERVICE_CONTROLS` in error).
6. Requester Pays buckets need a billing project (`--billing-project`).
7. Org policy / deny policies.

## 5. Data operations (changes)

| Operation | Safety |
| --- | --- |
| Upload / sync | Show source/destination/count; `gcloud storage rsync --dry-run` |
| Delete objects | Soft delete keeps them for the retention window, versioning keeps noncurrent versions; `gcloud storage rm -r` asks via the guard; confirm exact prefix |
| Restore | `gcloud storage restore gs://B/obj#generation` (soft-deleted) or copy a noncurrent generation |
| Lifecycle rule change | Delete actions are permanent once applied beyond soft delete; review conditions carefully |
| Storage class / Autoclass | Minimum storage durations and retrieval fees for Nearline/Coldline/Archive |
| Retention / Bucket Lock | Locked retention cannot be reduced or removed: human decision |
| Storage Transfer Service | Dedicated SA, scoped source/destination, no public sources |

## Never

- Grant `allUsers`/`allAuthenticatedUsers`, disable public access prevention or UBLA, set public ACLs (guard-blocked).
- Delete buckets or disable versioning/soft delete from an agent.
- Generate signed URLs with long expiry or with a privileged identity; never create SA keys to sign URLs.
- Copy production data to nonprod or local machines without a data-handling approval.
